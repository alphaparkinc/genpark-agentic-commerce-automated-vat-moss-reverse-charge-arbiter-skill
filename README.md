## 🛠️ MCP Tools Exposed
- `audit_eu_vat_reverse_charge`: Determine whether B2B transaction qualifies for Article 196 reverse-charge zero-rated VAT.
- `lookup_eu_member_state_vat_rate`: Retrieve standard destination VAT rate for B2C consumer digital goods.
